# 코일센터 음악 방향

2026-10-14. 로컬 창작 악보와 FM 합성으로 제작했다. 외부 음원·샘플·기존 게임 선율을 사용하지 않았다. 음악은 경영 판단과 대사 읽기의 배경이며 장면마다 별개의 전개를 갖는다.

| 곡 | BPM / 조성 | 선율·편곡 방향 |
| --- | --- | --- |
| 첫 발령 / title | 104 / C major | 0–4–2–1 도약 주제, 오보에와 작은 금관 도입. 0/.75/1.5/2.5박의 움직임 |
| 강철의 항로 / map | 100 / D major | 같은 음 반복에서 상승하는 항만 주제. 금관 리드와 반박 피아노, 이동하는 베이스 |
| 책상 위의 세계 / office | 80 / F major | 하행하는 목관과 반 박자 늦게 들어오는 응답. 타악 없이 베이스 두 번, 현악 여백 |
| 결재의 시간 / decision | 96 / A minor | 0–1–2–4 상승과 하행 답변, 두 마디 토닉 뒤 화성 이동. 낮은 현과 절제된 오보에 |
| 차가운 시황 / downturn | 76 / G minor | 4–2–1–0 하행, 낮은 음역 답변과 단조 VI/IV. 타악 없는 느린 목관 |
| 남겨진 항로 / ending | 88 / C major | 첫 발령의 0–4–2를 회상한 뒤 옥타브 도약. 새로운 화성·리듬·두 번째 선율 |

모든 곡은 4/4, 도입 4마디 + A–B–A′–C 각 8마디다. A′는 네 마디 끝의 선율 음역과 대선율을 확장한다. B는 각 곡의 별도 두 번째 선율을 사용하고 화성 출발점을 두 칸 이동한다. C는 그 선율의 조용한 재진술과 화성 출발점 네 칸 이동으로 A 복귀를 준비한다. 동일 악보를 조옮김해 곡 수를 채우지 않았다. 실제 선율·리듬·화성은 `music/score.mjs`에 명시돼 있다.

악기 팔레트는 FM 전자피아노, 둥근 베이스, 플루트/오보에, 얇은 현, 작은 금관, 팀파니·브러시다. 좌우 배치와 두 번의 짧은 반사음으로 작은 합주 공간을 만든다. 음표별 attack/release와 velocity를 적용하며, 실제 악기를 녹음한 오케스트라는 아니다.

서류는 고역 마찰 잡음, 도장은 저역 하강 진동과 둔한 잡음, 발주는 비정수 배음의 금속음으로 분리했다. 작은 FM 두 음은 확인/저장에, 낮은 두 음은 오류에 사용한다. 효과음의 의미 구분과 피로도는 실제 청취가 남아 있다.

프로토타입: `node scripts/render-audio.mjs --only title,office`. 두 곡만 manifest에 기록하므로 나머지 곡을 사용하는 빌드 전에는 전체 렌더를 실행한다. 프로토타입 기술 검사는 통과했으며 사람이 두 번 반복해 듣는 감성 평가는 미검증이다.
