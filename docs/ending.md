# 재임 엔딩 — 당신이 남긴 항로

마지막 결산 창을 닫으면 기존 결과표보다 먼저 재임 기록을 돌아보는 엔딩이 열린다. 정상 임기는 120초, 지급 불능·자기자본 소진·자료 부족은 60초다. 엔딩은 표현 계층이며 경제 계산, 난수, 기존 S–F 평가, 명예의 전당 기록을 다시 계산하지 않는다.

## 회사의 모습과 기존 평가

회사의 모습은 `s.history`, `s.hq`, `W.stats`, `W.miles`, `W.projectLog` 등 실제 완료 기록에서 읽는다. 누락 값은 0으로 채우지 않고 unknown으로 둔다. 12개월 미만이거나 어느 후보도 자격을 갖추지 못하면 공통 유형 「당신이 지나온 자리」를 쓴다.

각 후보는 필수조건을 모두 만족하고 네 보조 지표 중 두 개 이상이 참이어야 한다.

| 유형 | 필수조건 | 보조 지표 4개 |
|---|---|---|
| 성장 | 마지막3개월/첫3개월 평균 출하 ≥1.20 | 성장비 ≥1.35, 증설 이정표, 누적 영업손익 ≥0, 마지막3개월 영업손익 ≥0 |
| 재무 안정 | 누적 영업손익·순손익 ≥0 | 흑자월 ≥75%, 차입 한도 사용 ≤60%, 자금 압박월 ≤10%, 최종 자기자본 >0 |
| 고객 | 납품 ≥90%, 고객관계 ≥70 | 납품 ≥95%, 고객관계 ≥80, 부족월 ≤10%, 이탈 0 |
| 생산·품질 | 설비 ≥70, 평균 양품률 환산값 ≥97.8 | 설비 ≥80, 양품률 ≥98.5, 고장률 ≤1/24, 품질 문제율 ≤1/24 |
| 본사 기여 | 납품 ≥90%, 본사 신뢰 ≥70 | 누적 모법이익 목표 달성, 연간 목표 달성률 ≥75%, 신뢰 ≥80, 본사 소재 이익 >0 |
| 회복 | 임기 완료, 최종 자기자본 >0, 첫6개월 적자·마지막6개월 흑자, 누적 영업손익 >0, 마지막3개월 모두 흑자 | 흑자월 ≥50%, 차입금이 첫 결산의 85% 이하, 장기재고 ≤15%, 마지막6개월 흑자가 첫6개월 적자 절대값 이상 |

후보가 겹치면 보조 지표 점수 → 알려진 지표 수 → `회복, 생산·품질, 고객, 재무 안정, 본사 기여, 성장` 고정 순서로 고른다. 이 순서는 동률 해결용이며 우열이 아니다. 선택된 유형은 기존 본사 평가와 독립적이다. 같은 S–F 등급도 다른 회사 모습이 될 수 있고, 유형이 C/F를 승리로 바꾸지 않는다. 테스트용 synthetic fixture는 경계와 문구를 확인할 뿐, 여섯 유형을 실제 전략으로 모두 자연 달성했다는 증거가 아니다.

## 기억과 직원 인사

정상 엔딩은 실제 이정표·평가 완료 과제에서 기억 두 개, 조기 엔딩은 한 개를 고른다. 발생 날짜와 과제의 달성·부분 달성·미달을 그대로 보존한다. 같은 달의 첫 흑자와 누적 흑자 전환은 하나로 합치고, 기록이 부족하면 현재 지표 비교나 「기록에 남지 않은 순간을 덧붙이지 않습니다」를 표시한다. 미완료 과제는 성공으로 쓰지 않는다. 과거 원문은 「그때의 말」, 새 엔딩 대사는 「마지막 인사」로 구분하며 상세 결과에서 원문을 볼 수 있다.

직원은 기존 순서인 정 부장, 서 대리, 구 공장장, 한 부장, 오 과장, 린 매니저가 나온다. 납품, 장기재고, 피로·설비, 영업손익·차입, 품질 문제·양품률, 사기 지표에 따라 positive/concerned/neutral 표정과 인사가 달라진다. 조기 종료에는 짧은 인사, 0개월·종료 사유 누락에는 중립 문장만 쓴다.

## 감상과 조작

- 「잠시 멈춤/계속 보기」, 「다음 장면」, 「결과 보기」는 44px 이상의 실제 버튼이다. `Space`는 재생/정지, `ArrowRight`는 다음 장면, 창 상태의 `Escape`는 결과로 이동한다. 전체화면의 `Escape`는 먼저 창 화면으로만 돌아온다.
- 일시정지 중 다음 장면을 누르면 소리를 내지 않고 다음 경계에 머물며, 계속 보기에서 그 위치부터 시작한다. 숨김 탭에서는 위치와 소리를 멈추고 수동 정지는 복귀해도 유지한다.
- 오디오 준비가 5초를 넘거나 404·오디오 미지원이면 같은 위치에서 무음으로 이어진다. 브라우저 활성화가 필요하면 계속 보기와 결과 보기를 제공한다. 저장된 음소거와 master/BGM 0은 바꾸지 않는다.
- 엔딩 그림 → 장면별 기존 그림 → 집무실/지도 → HTML 안내 순으로 fallback한다. 어떤 실패에서도 자막과 결과 보기는 유지한다.
- 부분 모션은 같은 transport의 8fps 시계를 쓴다. 일시정지·숨김·그림 실패·게임 움직임 끄기·OS reduced-motion에서는 정지화다.

엔딩을 마치거나 건너뛰면 기존 결과표·CSV·다시 시작을 그대로 보여 준다. 「엔딩 다시 보기」는 **현재 메모리에 있는 완료 세션**에서만 제공한다. 과거 명예의 전당을 엔딩 도감으로 바꾸지 않으며, 다시 보기는 월·경제·난수·저장 bytes·명예의 전당 수를 바꾸지 않는다. 완료 checkpoint 복원은 자동 재생하지 않고 결과표에서 직접 다시 보게 한다.

엔딩은 `G.s`, `G.W`, checkpoint에 필드를 추가하지 않는다. 기존 `s/W/history`에서 다시 계산하므로 새 필수 저장 필드는 없다. 완료 checkpoint를 새 게임 객체로 거듭 복원할 때 기존 `G.recorded` 비저장 정책 때문에 명예의 전당이 중복될 수 있는 한계는 이번 작업에서 바꾸지 않았다.

## 그림·음원·캐시

여섯 유형 원화와 완료/조기 집무실 원화, 모두 여덟 장이다. 원본 PNG는 `source-art/ending/`, 배포본은 decoded RGBA가 같은 lossless WebP로 `art/ending/`에 둔다. 각 전달본은 3MiB 이하, 합계 18,928,332B다. common은 기존 집무실을 쓴다. 그림은 필수 shell precache에 넣지 않고 요청 성공 때만 선택 캐시한다.

전용곡은 「당신이 남긴 항로」 120초와 「다하지 못한 항로」 60초다. 전체는 24개 WAV, 74,420,068B(70.97251MiB)로 80MiB 한도 안이다. 두 곡은 22,050Hz·stereo·16-bit PCM, gain `.22`, loop 없음이다. 자세한 제작·해시는 [오디오 제작 기록](audio-production.md), 기술 검증은 [오디오 검증 기록](audio-verification.md), 그림 출처는 [아트 제작 기록](media-production.md)에 있다.
