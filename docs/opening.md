# 철의 항로 · 첫 playable 시안

72초의 classic-script 오프닝이다. Production Gonsama와 Ethan.J Studio 이름은 HTML 문자이고, 코일/일출 및 E/J 항로 문장은 별도 SVG다. 기존 지도·집무실·여섯 직원 초상을 사용하며 새 항구/냉간 공장 WebP는 `art/opening/`에서 요청한다. 실패한 장면 그림은 기존 지도 그림으로 대체한다.

| 초 | 장면 | 문자 |
|---|---|---|
| 0–4.8 | 코일/일출 문장 | Production Gonsama |
| 4.8–9.6 | E/J 항로 문장 | Ethan.J Studio |
| 9.6–19.2 | 항구 | 바다를 건너온 철은, |
| 19.2–28.8 | 지도 위 부두→공장 | 사람의 손에서 새로운 쓰임을 얻는다. |
| 28.8–40.8 | 냉간 코일 공장 | 없음 |
| 40.8–52.8 | 기존 여섯 직원 | 직원 이름 |
| 52.8–62.4 | 빈 집무실 | 이곳의 내일을 맡을 사람. |
| 62.4–72 | 회사 전경과 두 줄 제목 | 이제, 당신의 차례다. |

`ccOpeningState()`는 지연 초기화되어 번들 최초 두 render에 안전하다. UI는 `CCAudio.cinematicStatus().position`을 requestAnimationFrame에서 읽으며 별도의 진행 시간을 만들지 않는다. transport가 숨김/수동 정지/무음의 시간을 소유한다. 모든 이동·페이드도 그 위치로 계산한다. 게임 또는 OS의 움직임 줄이기는 위치 이동을 없애고 짧은 페이드로 대체한다.

최초 선택은 음악과 함께 보기/소리 없이 보기/바로 시작이다. 바로 시작은 게임 생성이 아닌 타이틀 이동이다. 음악 명시 선택만 기존 음소거 설정을 해제한다. 무음 선택/임시 음악 끄기는 음향 환경설정을 쓰지 않는다. 시작 클릭에서 transport 호출 전에 비동기 작업을 기다리지 않는다.

`coilcenter:opening:v1=seen`은 완주 또는 명시적 건너뛰기에만 기록된다. 실패 복구의 타이틀로는 기록하지 않는다. 저장 접근 실패도 진입을 막지 않는다. 종료는 세대 번호/단일 done 전이로 중복 처리되지 않으며 구독·RAF·Escape를 해제하고 타이틀 첫 버튼에 초점을 준다. 타이틀의 오프닝 다시 보기는 새 gate를 만든다. G, RNG, checkpoint에는 접근/쓰기하지 않는다.

8:5 무대의 전체 그림은 contain으로 표시한다. 320/390px 세로에서는 자막·44px 이상 조작을 그림 아래 배치하며 문서 스크롤을 허용한다. 자막과 버튼은 글자 배율을 반영한다. 이름/제목을 그림에 구워 넣지 않는다.

빌드는 opening 자산 바이트/경로를 해시와 release 목록에 포함한다. `art/opening/`은 음원과 같은 선택 캐시 경로로 200 응답만 캐시하며 미캐시 오프라인 요청은 503을 반환한다. 필수 shell 설치는 해당 자산을 요구하지 않는다.

검증: `node --test tests/opening.test.mjs tests/audio-ui.test.mjs tests/build.test.mjs`. tests/opening은 gate 중복 렌더, 재방문/재생, 무음 설정 보존, 장면 경계, 실패/저장 제한, 완료·건너뛰기 경쟁을 검증한다. 오디오 UI 검사는 opening 소유 중 title scene을 차단한다. build 검사는 선택 자산 배포·해시·설치 제외·캐시 성공·오프라인 실패를 검증한다. 실제 브라우저의 전체 감상, 숨김 재개, 모바일/130%·초점, 실제 청취는 통합 QA에서 별도 기록해야 한다.
