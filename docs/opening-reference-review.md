## 기존 시안과의 차이

검토 당시 시안은 두 새 배경 그림과 기존 지도·집무실을 넓게 펼치고, 여섯 직원을 격자로 동시에 표시한다. 작은 전체 화면 이동과 페이드로 장면을 교체한다. 기능적으로는 재생기와 삽화 몽타주가 완성됐지만, 참고 영상의 검은 여백·개별 인물 강조·서사 문구·독립적인 제목 연출은 충분히 반영하지 못했다.

참고 영상에 정지 그림과 글이 쓰인다는 점도 중요하다. 단순히 움직임을 많이 추가하는 것이 목표가 아니다. 그림의 배치, 제한된 색과 도트 질감, 인물 한 명에게 주는 화면의 비중, 이야기와 제목이 등장하는 순서가 우선이다. 원본 로고·캐릭터·음원을 복사하지 않고 우리 제작사와 코일센터의 이야기로 제작한다.

## 사용자 확정 조작 방식

게임 실행 → 별도 선택 없이 오프닝 → 종료 시 타이틀. 오프닝 화면 클릭·터치로 즉시 타이틀에 갈 수 있어야 한다. ‘음악과 함께 보기’, ‘소리 없이 보기’, ‘바로 시작’ 등의 선행 메뉴와 아래 재생 조작 메뉴는 필요 없다. 키보드로도 같은 건너뛰기 동작에 접근한다.

소리 자동재생은 브라우저 정책의 영향을 받는다. 기존 음소거 설정을 존중하고, 소리가 차단돼도 화면은 진행되며 선택 메뉴를 다시 요구하지 않는다. 이 조작 수정과 전체 그림·음악의 재연출은 다른 범위이며, 조작 수정만으로 레퍼런스 연출을 완성했다고 표현하지 않는다.
