# 픽셀 오프닝 원화 개정 — 보관 기록

이 시도는 사용자의 후속 요청으로 교체했다. 현재 오프닝은 본편 원화·초상과 원본 WebP를 사용하고, 강제 320×200 축소나 색상 제한을 하지 않는다. 아래 파일은 배포에서 제외하여 `source-art/opening/pixel-attempt/`에 보관한다.

2026-10-21. 사용자가 매끈한 스튜디오 인트로와 회화적인 배경을 거절하고 검은 바탕·적은 색·분명한 도트를 승인했다. 내장 image_gen.imagegen으로 두 원화를 새로 제작했다. API/CLI 우회 없이 각 장면을 독립 생성했으며 파일을 바꾸지 않고 배포 경로에 복사했다.

- 항구: `source-art/opening/pixel-attempt/harbor-pixel.png`; 생성 원본 `exec-1ae19fb3-0458-4a4d-b194-13d0fc3d6dc1.png`.
- 공장: `source-art/opening/pixel-attempt/factory-pixel.png`; 생성 원본 `exec-d4e43c66-09f4-46c5-b15a-6e24bc18c5e3.png`.

생성 원화는 1586×992이다. 이전 시도에서는 원화를 320×200 논리 화면에 보간 없이 렌더링하고 색을 제한했다. 원본 게임의 그림과 다른 거친 결과가 나와 이 처리를 제거했다. 기존 회화형 파일과 본편 지도·집무실·인물 원본은 유지했다.

## Harbor prompt

Use case: stylized-concept. Asset type: original low-resolution pixel-art background for a 1990-era DOS strategy game opening, 8:5 landscape, destined for a literal 320x200 pixel framebuffer. Create a NEW composition with obvious large square pixels and a uniform coarse logical pixel grid, like a carefully hand-drawn 320x200 16-color adventure-game screenshot expanded with nearest-neighbor. A quiet coastal cargo harbor at sunrise: one dark modern freight ship in left middle distance; right side contains a low cold-steel-coil warehouse, two simple blocky red gantry cranes and a few silver coil rings; distant hills in stepped silhouettes. Emphasis is clear shapes and generous dark water/sky, not intricate detail. ONLY about 16 clearly separated flat colors: black, very dark navy, two muted blues, dark teal, two green tones, brick red, gray, warm ivory and ochre. Sun is a small stepped disk; water highlights are sparse horizontal pixel dashes; cloud and hill shading use flat color bands and sparse checkerboard dithering. Pixel-sized edges MUST visibly step. Large simplified pixel clusters, 1-2 pixel contours. All elements share the SAME pixel size. No cinematic lighting, gradients, glow, soft shading, photorealism, painterly brushwork, high-frequency texture, 3D render, smoothing, realistic reflections. No text, border, interface, logos, letters. No sailboat, no furnaces, molten steel, refinery or smoke. This should look like a real modest vintage PC game illustration, not an expensive modern painting with noise.

## Factory prompt

Use case: stylized-concept. Asset type: original low-resolution pixel-art background for a 1990-era DOS strategy-game opening, 8:5 landscape, for a literal320x200 pixel framebuffer. NEW image in strict chunky 16-color pixel art, enlarged nearest-neighbor with very apparent square pixels on a single consistent coarse grid. Interior of a cold-steel-coil processing warehouse: three readable large silver coil rings in foreground on dark wooden saddles, one modest slitting/leveling line in middle ground, a horizontal overhead yellow gantry crane and broad high roof beams. Two very small helmeted worker sprites show scale. Low-detail, strongly composed with black negative shapes, clear machine silhouettes, big flat areas. ONLY about16 discrete colors: black, navy, darkblue, charcoal, steelgray, graywhite, darkteal, mutedgreen, ochre, palegold, mutedbrown. Shade silver coil surfaces with exactly3-4 stepped bands and a few checkerboard pixels; NO polished chrome/realistic lighting/reflections. Light through windows forms flat hard-edged gold pixel rectangles, not rays or bloom. True manually clustered320x200 pixel-game aesthetic. No smooth diagonal edges, gradients, glossy rendering, dense painterly detail, photography, miniature diorama, blur, noise, film effects. No readable text or lettering, border, UI, logo. No smelting, blastfurnaces, glowingsteel, sparks, fire or smoke. Original industrial art, understated earlyPC strategy game rather than modern cinematic illustration.
