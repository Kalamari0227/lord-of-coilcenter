# 철의 항로 · 본편 원화 오프닝

72초의 classic-script 오프닝이다. 본편과 같은 원본 이미지와 HTML 글자를 전체 화면에 표시한다. 항구/냉간 공장은 `art/opening/harbor.webp`, `factory.webp`, 지도·집무실은 `strategy-map.png`, `strategy-office.png`를 사용한다. Production Gonsama와 Ethan.J Studio는 사용자가 선택한 C안의 유려한 붓 흘림체다. 승인된 불투명 원본 `art/opening/studio-calligraphy.png`(1536×1024)를 변경 없이 사용하고, 3:1 프레임에서 첫 장면은 위쪽 절반, 두 번째는 아래쪽 절반을 표시한다. 투명 추출 시도는 붓 획과 색이 달라져 채택하지 않았다. CSS로 표시 영역만 구분하며 원본 재생성·래스터 편집·다운샘플링을 하지 않는다. 최대 900px, 화면 폭의 90%와 장면 안쪽 폭 안에서 표시하고 작은 가로 화면에서는 높이 여유 96px도 유지한다. 이름은 이미지 alt로 제공하며 이미지가 실패하면 본편 서체의 HTML 이름으로 대체한다. 이전 심벌이나 별도 이름을 중복 표시하지 않는다. 나머지 글꼴은 본편의 `--cc-font-title`/`--cc-font-body`, 색은 본편 토큰을 사용하며 추가 글꼴을 다운로드하지 않는다.

장면은 최대 1480px이고 원본 그림은 contain으로 비율을 보존한다. 휴대폰에서는 화면 너비에 맞추고 자막은 그림 아래 별도 공간에 표시한다. 직원은 `ccPortraitMarkup`의 기존 atlas 초상을 정사각형 3×2 격자로 표시하며 이름은 HTML이다. 휴대폰 이름·자막은 최소 17px에 `--cc-text-scale`을 곱한다. 긴 이름은 줄바꿈하며 숨기지 않는다. 전체 장면의 저해상도 재샘플링·40색 양자화·비트맵 문자 처리는 제거했다. 그림 실패 시 error 핸들러를 한 번만 실행하여 기존 지도 fallback을 사용하고, 지도까지 실패해도 시계와 HTML 문구·건너뛰기를 유지한다.

높이 540px 이하의 화면에서는 너비와 관계없이 직원 격자의 여백과 초상 크기를 줄인다. 초상 높이는 화면 높이에서 이름의 글자 배율과 장면 여백을 뺀 범위 안에 두어 작은 가로 휴대폰에서도 여섯 얼굴과 이름을 함께 표시한다.

`ccOpeningState()`는 지연 초기화되어 번들 최초 두 render에 안전하다. 새 페이지 로드마다 기존 seen 값에 관계없이 오프닝을 열고 음악 재생을 시도한다. 같은 문서의 렌더·새 게임·타이틀 복귀에서는 다시 시작하지 않는다. 타이틀의 오프닝 다시 보기는 새 재생을 시작한다.

UI는 `CCAudio.cinematicStatus().position`만 requestAnimationFrame에서 읽는다. 음향이 지원되고 설정이 켜져 있으면 기존 수동 cinematic API를 자동 호출하여 오디오 활성화·음원 준비가 완료된 뒤 0초부터 영상과 음악을 함께 시작한다. 준비 중에는 첫 로고를 보이는 상태로 유지한다. AudioContext가 사용자 입력을 기다리면 「화면을 누르면 음악과 함께 시작합니다.」를 표시한다. 첫 클릭·탭·Enter·Space는 resume를 입력 이벤트 안에서 호출하고 소비하며 오프닝을 종료하지 않는다. 브라우저가 자동 재생을 허용하면 입력 없이 시작한다. 음원 실패나 오디오 미지원에서는 기존 72초 무음 transport로 진행해 타이틀 접근을 유지한다. 숨김/복귀는 동일 위치에서 정지/재개한다.

별도 시작 선택·재생 도구막대·실패 메뉴·footer가 없다. 첫 클릭/탭/Enter/Space에서 오디오 활성화를 먼저 호출하고, 같은 입력 안에서 `document.documentElement.requestFullscreen()`을 요청한다. 이미 음악이 자동 재생 중이어도 이 첫 입력은 전체화면 전환에만 쓰고 오프닝을 유지한다. 이후 같은 입력은 타이틀로 건너뛴다. 전체화면은 타이틀·부임 설정·본편까지 유지된다. 입력 없이 오프닝이 끝났거나 먼저 건너뛴 경우에는 타이틀의 새로 시작·이어서 하기에서도 최초 전환을 요청한다. 자동 요청은 문서당 한 번이며, Esc나 화면 설정에서 창으로 돌아온 뒤에는 다시 강제 진입하지 않는다. 지원하지 않거나 요청이 거절된 환경은 창 화면에서 계속 진행한다.

전체화면 중 Escape는 화면 크기만 되돌리고 오프닝을 유지한다. 전체화면 동안 document의 capture 키 처리로 본편과 열린 보조 창에서도 먼저 화면 크기를 되돌리며, 같은 입력이 오프닝 건너뛰기나 dialog 닫기로 이어지지 않게 한다. 전체화면을 나가면 이 키 처리를 해제한다. 창 화면의 Escape는 준비·활성화 대기 중에도 즉시 건너뛴다. 「화면 설정」에서 전체화면/창 화면을 전환할 수 있고 실제 `fullscreenchange`에 맞춰 버튼·상태 문구를 갱신한다. 설정 창을 닫으면 설정 구독을 해제하고, 전체화면 세션이 끝나면 남은 감시도 해제한다. 전체화면 상태는 게임 저장이나 음향 설정에 기록하지 않는다. 오프닝 이벤트 기본 동작과 전파를 막고, 종료 시 구독·RAF·키보드/클릭 핸들러를 해제한다. 종료는 단일 done 전이로 중복 처리되지 않으며 타이틀 첫 명령에 초점을 준다. transport ticket과 opening generation은 이전 준비 완료가 건너뛴 오프닝을 되살리지 못하게 한다.

오프닝 시작·첫 입력·다시 보기는 음향 설정과 seen 값을 쓰지 않는다. 저장된 음소거 또는 master/BGM 0이 있으면 음원을 요청하거나 오디오 컨텍스트를 만들지 않고 72초 무음 타임라인을 바로 진행한다. 첫 입력은 기존 전체화면 진입·건너뛰기 동작을 따르며 음소거와 모든 사용자 음량을 그대로 보존한다. G, RNG, checkpoint에 접근하거나 쓰지 않는다. 저장/업데이트/도움말 어댑터는 오프닝 중 컨트롤을 붙이지 않는다.

기본 음향은 켜짐(master 70%, BGM 45%)이다. 최초 활성화 클릭은 첫 오프닝 안에서 처리하므로 타이틀에서 음악을 켠 뒤 다시 보기를 할 필요가 없다. OS/브라우저의 오디오 중단을 사용자 음소거로 기록하지 않는다. 중복 재개와 늦은 준비 완료가 소리를 겹쳐 재생하거나 건너뛴 오프닝을 되살리지 않는다. 브라우저가 요구하는 최초 사용자 입력 자체를 우회하지는 않는다.

전환은 장면 경계의 짧은 opacity fade다. 전체 그림과 글자의 위치는 고정한다. HTML은 장면이 바뀔 때 한 번만 생성하며 transport 위치로 장면 opacity를 갱신한다. 이미지 오류 핸들러는 새 장면 HTML을 붙인 뒤 연결하며 첫 실패에서 해제한다.

2026-10-22 요청에 따라 항구·지도 수면과 공장 가동부에 고전 게임식 부분 반복 효과를 추가했다. `opening-motion.js`는 원화와 같은 1586×992 viewBox의 SVG를 `preserveAspectRatio="xMidYMid meet"`로 겹친다. 원화의 contain과 동일한 영역에 맞으므로 세로·가로 화면의 여백에서도 물결 위치가 어긋나지 않는다. 지정한 수면 마스크 안에서 7px 띠를 번갈아 최대 x±3px/y1px 이동하고, 공장에서는 가동 롤러와 전진 강판 안으로 제한한 금속 질감과 얇은 반사선을 이동한다. 배·건물·원경·받침 위 저장 코일은 정지한다. 원본 이미지 파일을 수정하거나 동영상·canvas·필터·새 라이브러리를 추가하지 않는다.

부분 효과는 같은 transport의 `floor(position * 8)`에 따라 8fps로만 갱신한다. 별도 RAF·반복 타이머·난수는 없고 기존 `ccOpeningTick()`에서 호출한다. `motionOff()` 또는 OS reduced-motion이면 SVG를 숨기고 원화만 표시한다. 원화가 아직 로딩 중이면 효과도 숨기며, 음향 일시정지·숨김 탭에서는 마지막 프레임을 유지한다. CSS에서도 `.nomotion`과 reduced-motion을 적용한다. 장식은 `aria-hidden="true"`, `focusable="false"`, `pointer-events:none`이라 자막과 기존 건너뛰기를 방해하지 않는다. 원화 실패에는 효과를 제거한 뒤 기존 지도 fallback을 사용한다. 늦게 실패한 이전 장면 이미지는 현재 효과를 제거하지 않는다. 장면 변경·종료 시 참조와 SVG를 해제하며 재생마다 새 효과를 만든다.

빌드는 opening 자산 바이트/경로를 해시와 release 목록에 포함한다. `art/opening/`은 음원과 같은 선택 캐시 경로로 200 응답만 캐시하며 미캐시 오프라인 요청은 503을 반환한다. 필수 shell 설치는 해당 자산을 요구하지 않는다.

검증: `node --test tests/opening.test.mjs tests/fullscreen.test.mjs tests/preferences.test.mjs tests/audio-cinematic.test.mjs tests/audio.test.mjs tests/audio-ui.test.mjs`. fresh/seen 자동 시작·중복 렌더·즉시 재생·첫 입력의 오디오/전체화면 호출 순서·자동 재진입 방지·전체화면 설정 구독과 오류 처리·클릭/키보드 건너뛰기·부가 메뉴 차단·장면 경계·이미지 fallback·실제 HTML 자막/이름·시스템 폰트 재사용·설정/checkpoint 보존과 기존 오디오 동작을 검사한다. 실제 브라우저의 전체화면·Esc·데스크톱/휴대폰/130% 배치와 초점은 통합 QA에서 별도 기록한다. 물리 iOS와 사람의 청취는 별도 검증이다.
